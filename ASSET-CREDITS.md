# Artwork and credits

## Alien sprites

**Alien Set** by **The_Scientist___**, published on OpenGameArt.org on 23 February
2019. Source: https://opengameart.org/content/alien-set

Download: https://opengameart.org/sites/default/files/Alien%20Sprites.zip

The author lists the pack as **CC0**, with credit appreciated but not required.
CC0 terms: https://creativecommons.org/publicdomain/zero/1.0/

All 17 supplied PNG files are retained unchanged under `assets/aliens/`.
The game uses `alien1_g.png`, `alien2_p.png` and `alien3_r.png`. The remaining
colour variants, bullet and splat sheets are included for you to experiment with.

These are alternative reusable alien graphics, not the original Namco arcade
sprites. No original game ROM, music or extracted arcade artwork is included.

## Project code and sound

Based on Charles Swires' supplied Saturn project, including its Java PCM sound
effects. New game logic, Swing rendering and project files were created for this
Galaxian-inspired adaptation. Existing proprietary source notices are preserved.

Copyright © 2026 Charlie's Tenacity Ltd. All rights reserved, for project code.
The third-party CC0 artwork retains its separate terms above.

The player ship, stars, projectiles and explosion particles are drawn directly
in Java. Sound effects are synthesized at runtime; no third-party recordings
or sound libraries are used.

Galaxian is a name associated with Namco's arcade game. This is an independent
inspired project, not an official or exact reproduction.
